## 3.1 细节（示例步骤，4 问）

### T1 首次发送（P1）

1. 目标：输入框 placeholder「输入消息，Enter 发送，Shift+Enter 换行」→ 知道要做什么（通过）。
2. 控件：输入框、发送按钮、字数可见；发送按钮在空草稿时禁用（预期一致）。
3. 预判：Enter 发送、Shift+Enter 换行有提示（通过）。
4. 恢复：发送失败/离线有提示；草稿是否保留需确认（`INT-06`）。
摩擦：`INT-06`（P1，发送失败时草稿保留路径需要 e2e/单测证明，当前 `CMP-PERSIST-01` 只覆盖成功刷新）。

### T2 修改设置（P1）

1. 目标：顶栏「设置」→ dialog，分页导航可见（通过）。
2. 控件：通用/模型/本地 Provider/Agent/工具与审批/网络与检索/…；字段多，单屏主要选择 >7（`INT-07`）。
3. 预判：底部唯一「保存」，保存后有 toast（通过）。
4. 恢复：保存失败/冲突是否有清晰修法需确认（`INT-04`/`INT-08`）。
摩擦：`INT-07`（P1，设置分区多、无搜索/最近使用）；`INT-04`（P2，错误定位到字段的提示可更明确）。

### T3 ⌘K + 右栏（P2）

1. 目标：header 已有可见命令按钮 + tooltip（`ui-shell`），首次用户可通过按钮发现；⌘K 快捷键本身提示弱（`INT-01`，P2）。
2. 控件：Ctrl+K 打开命令面板，搜索框聚焦；Esc 关闭并回焦点（通过）。
3. 预判：命令列表分组/hint 可见（通过）。
4. 恢复：右栏关闭按钮 `×` 有 aria-label，但视觉上只有符号（`INT-10`，P2）。
摩擦：`INT-01`（P2，快捷键提示可更明确，入口已可见）；`INT-10`（P2，右栏关闭按钮只有 `×`，可加 tooltip/可见 label）。
