## 3. P0（阻塞）

### P0-1 · 安全评审不是 docs/21 §10 的 13 项门禁

- `spec.md:7-9`：仅“检查清单”+`grep` 密钥/`unsafe`/`unwrap`+路由权限+`cargo deny/audit 若可用`；没有：
  - 威胁模型/资产/信任边界/P0 风险缓解与测试；
  - 认证绕过、JWT 吊销、CSRF、SSRF、zip 穿越、WASM 逃逸、命令注入、rebinding 用例；
  - 密钥生命周期（master.key 恢复、JWT/更新签名轮换）；
  - 审计哈希链 + WORM 锚定验证、钱审计矩阵；
  - `cargo-deny` + pnpm audit + 镜像扫描（无高危）；
  - 隐私口径评审（不声称“服务端不读取会话”除非已验证）。
- `cargo deny/audit “若可用”` 与 docs/18/21 强制门禁冲突；`security-audit.sh` 未定义 severity/owner/sign-off，无法证明“0 高危未修”。

**修法**：按 docs/21 §10 建 13 项 checklist（每项命令/证据/owner/结论），强制 `cargo deny`、`pnpm audit`、镜像扫描；补 threat model 文档与 P0 缓解测试；补密钥生命周期/审计链/隐私口径；`security-audit.sh` 输出 JSON（severity、rule、file:line、status、owner）。

### P0-2 · 备份/恢复只覆盖 PG，漏 /data、PITR、master.key 与整机恢复

- `spec.md:13`：`pg_dump → 临时库 → 表数/关键行校验`；没有：
  - `/data`（WASM app DB、配置、日志）；
  - WAL 归档/PITR 与恢复点；
  - `.env` 剥离/恢复 MASTER_KEY；master.key 离线分离；
  - `VERSION/CHANNEL.json`/portal/client 产物；
  - 整机恢复（server 启动 + 迁移 + 登录 + 业务 smoke）。
- `docs/20:44-57` 明确这些是备份内容；M6 退出（docs/20:131）要求备份→升级→回滚→恢复全链路，spec 只有 dump/restore 临时库。

**修法**：备份脚本覆盖 PG `-Fc`+WAL/PITR、`/data`、`.env`（剥离 MASTER_KEY）、VERSION/CHANNEL；恢复演练：空/旧库 restore→迁移→启动→登录/业务 smoke；master.key 手工注入验证；补备份加密/分离/恢复失败回滚。

### P0-3 · 可复现构建语义与范围不成立

- `spec.md:25`：`SOURCE_DATE_EPOCH=0`，构建两次 `zk`/`zk-server` 比较 sha；“差异分类记录”即可。docs/12 M6 退出要求“可复现校验通过”，不是“记录非确定项”。
- 未固定 toolchain/Cargo.lock/pnpm lock、`--locked`、`--remap-path-prefix`、build-id、Tauri bundle、admin/desktop/web；只比较两个 CLI/服务端二进制，不能证明三平台产物/镜像可复现。

**修法**：固定 rust/node/pnpm 版本+锁文件+`--locked`+`--remap-path-prefix`+`SOURCE_DATE_EPOCH`；覆盖 `zk`/`zk-server`/`zk-desktop`/admin dist/镜像 tar；两次冷构建比对；差异必须为 0，非确定项要 ADR+消除，不得以“记录”代过。

### P0-4 · 故障注入只停 DB/readyz，不证明无数据损坏/全链路

- `spec.md:14`：停 DB→readyz 非 200→恢复；没有 kill -9 迁移中/事务中、PG crash、OOM、磁盘满、网络分区、审计写失败 fail-closed；没有“数据不丢/不损坏”的行/账/审计断言。
- docs/12 M6 退出要求“故障注入不导致数据损坏”；docs/20:131 要求备份→升级→回滚→恢复全链路；spec 只进程级 DB stop。

**修法**：故障矩阵（kill -9 迁移/事务、PG crash、磁盘满、OOM、网络分区、审计失败）；每项断言账本/审计/迁移一致性；补 backup→upgrade→rollback→restore 全链路脚本与证据；无 Docker 时进程级+故障点明确标 unverified。
