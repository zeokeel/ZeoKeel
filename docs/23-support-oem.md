# 23 · OEM 交付、客户接入与支持（补充规范）

> 状态：Plan v3.2 补充规范。补齐 `09` 中"只有我方构建流水线、没有客户可执行流程"的缺口：
> **客户接入 → 构建 → UAT → 签收 → 交接 → 支持/升级责任**。
> 参考仓库只作参考；本文定义我们自己的流程与交付物。

## 1. OEM 客户接入（Intake）

客户必须提供（缺项不启动构建）：

| 项 | 负责方 | 验收 |
| --- | --- | --- |
| 联系人与交付信息 | 客户 | 支持联系人、升级窗口、交付地址 |
| 渠道 id | 我方 | `^[a-z0-9][a-z0-9-]{0,31}$`、非保留字、跨渠道唯一 |
| 域名/DNS/TLS | 客户 IT + 我方指导 | 域名可解析、证书可用（或 `TLS_MODE=internal`） |
| `defaults.server_url` | 客户确认 | 非空=免填；空=首配（二选一写入 `channel.json`） |
| IdP 元数据（如 OIDC/LDAP） | 客户 IT | 测试连接成功 |
| Logo/品牌素材/文案 | 客户 | 符合 `09` §3；跨渠道唯一校验通过 |
| 平台范围 | 客户 | windows/macos/linux 子集；缺平台不渲染 |
| 支持联系人/升级窗口 | 客户 | 写入交接单；紧急联系人 7×24 或 5×8 |
| 数据/合规要求 | 客户 | 数据留在客户服务器；出境由客户自行评估 |

## 2. RACI（必须写进交付说明）

| 活动 | 客户 | 我方 | 说明 |
| --- | --- | --- | --- |
| 品牌素材/文案 | R | C | 客户提供，我方校验 |
| 域名/DNS/TLS | R | C | 客户运维 |
| IdP 配置 | R | C | 客户 IT；我方提供元数据模板 |
| 构建/签名/产物 | I | R/A | 我方 CI 唯一出口 |
| 部署/升级 | R | C | 客户 IT 执行；我方提供 runbook/远程支持 |
| 备份/恢复 | R | C | 客户执行；我方验收脚本 |
| 安全补丁/新版本 | I | R/A | 我方发布；客户选择升级窗口 |
| 日常用户支持 | R | C | 一线客户 IT；二线我方 |
| 事故响应 | R | C | 客户通报；我方技术支援 |
| 数据控制者 | R/A | C | 客户自行控制数据；我方是软件提供方，不处理数据 |

## 3. 构建与交付包

构建输入：客户子仓（`channel.json` + 素材 + 可选代码包）+ 主仓 tag + 锁定依赖。
产物（每个渠道独立目录）：

```text
（产物命名以 `09` §4–§5 为唯一真源；本节只列目录结构）
dist/<version>/<channel>/
├─ images/<server-image>.tar.zst
├─ clients/{windows-x64,macos-*,linux-x64}/...
├─ CLIENT-RELEASE.json
├─ CHANNEL.json
├─ SHA256SUMS
├─ SBOM/
├─ VERSION
├─ deploy/（compose/Caddyfile/.env.example）
├─ docs/（安装/升级/备份/回滚/FAQ）
└─ HANDOVER.md（交接单）
```

规则：

- 产物带渠道品牌，**绝不进公开 release**；OEM 更新面由客户自建（或我方托管，交付说明写明）。
- 镜像/客户端/清单签名链完整；Windows 不签名（提示 SmartScreen），macOS 公证证书归属写入交付说明。
- 交付前跑 `09` 的白标门禁 + 本文件 UAT。

## 4. UAT 与签收

### 4.1 UAT 清单（客户现场，必须逐项签字）

- [ ] 门户可访问、品牌/文案正确、下载三平台安装包。
- [ ] 按渠道配置验收：`server_url` 非空→登录页无地址输入；为空→首配页输入/保存；修改地址需重登。
- [ ] 登录（local/OIDC/LDAP）成功；禁用用户下一次请求 401。
- [ ] 首轮对话流式 + 工具 + 审批 + 扣费；余额不足提示正确。
- [ ] 技能上传/审批/安装/删除同步；连接器启用/停用；应用打开/隔离。
- [ ] 强制更新：旧客户端被 426 拦截 → 从服务端升级 → 恢复使用。
- [ ] 备份 → 升级 → 回滚 → 恢复 全链路演练通过。
- [ ] 审计可查：登录/充值/扣费/管理操作；审计员只读。
- [ ] 离线/内网场景（如适用）：无外网可导入镜像/客户端包。

### 4.2 签收

- 客户签署 UAT 报告 + 交接单；记录版本/渠道/镜像 digest/SHA256。
- 遗留问题清单（P0 必须清零；P1 有修复计划与期限）。

## 5. 交接包（Handover）

| 内容 | 说明 |
| --- | --- |
| 版本/渠道 | `VERSION`、`CHANNEL.json`、镜像 digest |
| 凭据 | 管理员初始密码（首登改密）、`MASTER_KEY` 交付方式（离线）、更新面凭据（如托管） |
| 文档 | 安装、升级、回滚、备份恢复、故障排查、FAQ、安全说明 |
| 支持 | 联系人、升级窗口、SLA、二线升级路径 |
| 合规 | SBOM、许可证/NOTICE |
| 回滚包 | 上一版镜像 + 客户端（至少保留 2 版） |

## 6. 支持分级与内部目标（不构成合同 SLA）

| 级别 | 范围 | 响应 | 解决目标 |
| --- | --- | --- | --- |
| P0 | 全站不可用/数据丢失/安全事件 | 15 min（7×24） | 4 h 内缓解 |
| P1 | 核心功能不可用/资损风险 | 1 h（5×8） | 1 工作日 |
| P2 | 部分功能/性能下降 | 4 h（5×8） | 3 工作日 |
| P3 | 咨询/文档/小问题 | 1 工作日 | 下个版本 |

- 一线：客户 IT（按 runbook 自查）；二线：我方支持；三线：研发。
- 支持入口：工单/邮件/电话（交付说明约定）；禁止直接给客户 root/DBA。
- 升级/补丁：安全补丁优先；客户可选择窗口；重大版本提前 30 天通知。

## 7. 常见问题与边界

- **"零外网依赖"**：指部署/更新/客户端分发不依赖外网；**AI 调用仍需出网**（客户配置的上游或代理）。文档/销售不得混淆。
- **OEM 锁定地址迁移**：同渠道 `server_url` 不可变（`09` §3）；换域名必须走**新渠道 + 导出/导入**（新 app_id/data root，旧客户端随旧渠道退场）。不提供运行期改地址。
- **品牌构建期固定**：运行期不可换品牌；换牌=重新构建/交付，数据根不变（同渠道升级）。
- **OEM 定制代码**：由我方开发并入库（D61）；不接受第三方闭源预构建包。
- **Windows 不签名**：所有渠道一致（ADR-033）；交付文档提示 SmartScreen，不提供 OEM 签名例外。
- **数据归属**：数据在客户服务器；我方不读取会话内容；退出时由客户自行导出/删除（D63 不做 DPA）。
- **Powered by**：官方默认显示；**OEM 默认不出现**，可按渠道配置（D62）。
