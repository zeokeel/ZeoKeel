### B4. 更新（v3.2 已定）

| # | 结论 |
| --- | --- |
| D54 | **个人版**更新只走 **GitHub Releases**（stable/beta，`latest.json` + `SHA256SUMS`） |
| D55 | **企业版服务端**从**自建更新服务器**取镜像包，**必须手动升级**（备份→校验→`docker load`→compose up→readyz），不自动升级 |
| D56 | **企业版客户端只从登录的服务端更新**，版本与服务端镜像内客户端 1:1 配对；服务端版本变则客户端强制跟进 |
| D57 | **渠道可内置服务端地址**（`channel.json.defaults.server_url`）：非空 → 登录页只输账号/密码、地址不可编辑；为空（官方默认）→ 首配页输入并本地保存（设置中可改）；OEM 可预置也可留空 |
| D58 | **个人版优先；企业版 = (个人版 − 个人专属包) + 企业管控包**（登录/网关/商店客户端/服务端/管理台），不另造客户端基线 |
| D59 | **官方企业版也是渠道**（`official`）：`server_url` 默认空、客户登录时自配；任意渠道都可指定或留空；官方/OEM 同一构建链路 |
