# 17 · 历史决策存档（v3.1 时点，不具权威）

> **本文件是历史快照，不提供现行规范，不得作为实现依据。** 现行结论见 `15`（D1–D65）与 `13`（ADR-001…056）。
> 保留原因：追溯“当时为什么这么定”；引用请使用 15/13。

## 1. 总基调变更：从"强管控"改为"服务端弱管控"

| 项 | v3（旧） | v3.1（新，已定） |
| --- | --- | --- |
| 服务端职责 | （v2 旧）认证、组织、钱包、网关、技能、连接器、应用、审计、**策略下发/工具白名单** | **（v3.1 现行）只管认证相关 + 商店功能 + 钱包/网关 + 审计 + 管理台** |
| 工具 | 服务端下发白名单 | **不做白名单，默认全部允许** |
| 网络 | 默认关闭 + 域名白名单 | **默认开启，允许所有网站与地址，不做任何限制** |
| 企业审批 | 服务端下发审批策略，员工不可改 | **不做企业审批那套；员工拥有客户端全部能力** |
| 员工限制 | 设置页收窄、只读策略 | 客户端能力完整；服务端不干预员工怎么用客户端 |

**结论**：企业版的"可控"体现在**身份、钱、商店内容、审计、版本**五件事上，而不是限制员工的操作。
`00-design-principles.md` 已按此重写。

## 2. 逐条决策

| # | 决策 | 影响 |
| --- | --- | --- |
| 1 | 服务端弱管控；能力/工具全部下发 | 删除工具白名单、企业审批、网络限制、策略下发中的对应部分 |
| 2 | 个人版没有应用中心 | 个人版不含 WASM 应用包；文档与产物同步 |
| 3 | 企业版网关只支持 **Responses API** | 删除 `/v1/chat/completions`；只保留 `/v1/responses`（流式/工具调用） |
| 4 | 流式已输出部分内容后超额：**允许透支** | 结算允许负余额；记录欠费；下次请求前阻断 |
| 5 | **峰谷价要做** | 价格表需支持时段（峰/谷）与按模型定价；结算按请求发生时段 |
| 6 | 月发放**直接发放**，不折天数 | 月作业按配置金额一次性到账；新员工当月也全额 |
| 7 | **仅管理员手动加充值** | 不提供自助充值/兑换码；管理台操作 + 审计 |
| 8 | **去掉用户组/部门** | 删除组织树、部门可见范围、部门管理员概念；技能可见范围当时定为全员/私有，后由 D47 改为全员/指定用户 |
| 9 | 员工禁用后 JWT **立即失效** | 每请求校验 `token_epoch`（或等价版本），不再等 access 过期 |
| 10 | 钉钉/企微/飞书优先级低；认证形态按各家官方 | 后续独立包，不强求统一 OIDC 形态 |
| 11 | 技能 16MB、允许资源、**先不做扫描**（记录 TODO） | 上传校验大小/结构；扫描作为后续增强 |
| 12 | 删除技能 → 已安装用户**自动同步删除** | 客户端收到 `skill.deleted` 事件后移除本地副本 |
| 13 | 企业版 MCP **允许本地 stdio**，管理员配置即可用 | 连接器支持 stdio/http/sse；stdio 命令由管理员配置 |
| 14 | MCP OAuth **回调由客户端承担** | 客户端处理授权码与令牌，令牌本地保存（D53）；服务端只下发连接器配置与 client secret |
| 15 | WASM 开发语言**待调研**（Rust 宿主） | 已启动 `research/wasm-languages.md`；v1 语言集待结论 |
| 16 | **员工可以上传应用** | 员工上传 → 管理员审核/上架；归属与版本规则同技能 |
| 17 | **不做 Windows 代码签名** | 交付文档与路线图移除；安装时提示 SmartScreen 风险 |
| 18 | demo 仓库建在 **`zeokeel` 组织** | 已确认账号 `zeokeel-dev` 是 org admin；索引仓自建（demo：`zeokeel/demo-oem-index`），参考仓不直接使用 |
| 19 | 企业版员工拥有客户端**全部能力**，无企业审批 | 删除服务端审批策略；客户端审批仍可作为本地功能 |
| 20 | 工具白名单不做，默认全部允许 | 删除策略中的工具白名单与 `POLICY_DENIED` 场景 |
| 21 | 网络默认开启、允许所有地址、不做限制 | 删除网络域名白名单与默认关闭；安全责任由客户网络边界承担 |
| 22 | 管理台增加**只读审计员**角色 | 角色：超管、审计员（只读）、员工；审计员仅能看审计/用量等只读页 |
| 23 | WASM 语言与 ABI 已调研（`research/wasm-languages.md`） | v1 Tier-1：Go(wasip1)+Rust(wasip1)；帧 `RS<len>\n<JSON>` + `db.*` 宿主函数；M4 先 Go，GA 前加 Rust；Wasmtime 锁 LTS |
| 24 | 可见范围 = **全员 / 指定用户**（无部门/私有） | 技能与应用一致；`content_grants` 支持 user |
| 25 | 月发放默认全员，支持**累加/覆盖**，默认累加 | `wallet_grant_rules.mode` |
| 26 | macOS **需要公证**；证书后配，CI 先就绪 | ADR-037；Windows 仍不签 |
| 27 | 服务端门户 = **员工客户端下载**；**不做 OEM 自助门户** | ADR-038 |
| 28 | 未登录企业版只显示登录页 | 无本地功能 |
| 29 | 审计 ≥180 天、用量 ≥12 个月；可配置但不得低于下限 | `system_settings.min_value` |
| 30 | 个人版更新 = GitHub Releases；企业版服务端 = 自建更新服务器 + 手动导入镜像；企业版客户端 = 只从登录服务端 1:1 更新 | 见 ADR-041、`09` §7 |
| 31 | OEM 渠道内置服务端域名（`channel.json.defaults.server_url`），登录页免填地址 | 见 ADR-042、`09` §2–§3 |
| 32 | 个人版优先；企业版 = (个人版 − 个人专属包) + 企业管控包 | 见 ADR-043 |
| 33 | 渠道与版本正交：官方企业版也是渠道（server_url 可空/可指定），OEM 同一链路 | 见 ADR-044 |
| 34 | demo 仓库建在 `zeokeel` 组织 | 已创建（私有）：[demo-oem-acme](https://github.com/zeokeel/demo-oem-acme)、[demo-oem-index](https://github.com/zeokeel/demo-oem-index)（含 submodule）、[demo-wasm-app](https://github.com/zeokeel/demo-wasm-app)；索引仓自建，不使用参考仓 |
